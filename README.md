# Disease Prediction from Medical Data

## Project Overview

This project focuses on predicting disease outcomes from medical data using machine learning techniques.

## Tools and Technologies

* Python
* Google Colab
* Pandas and NumPy
* Scikit-learn
* Matplotlib and Seaborn

## Source Code

The complete project source code is provided in the Jupyter Notebook in this repository.

## How to Run

1. Open the Jupyter Notebook.
2. Open it in Google Colab.
3. Upload or connect the required dataset.
4. Run the notebook cells in order.
